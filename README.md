# Questline

A cross-platform mobile RPG quest-board app. Real-world tasks, gamified through a Skyrim/Harry Potter-inspired framework. Built with React Native + Expo.

> **Source of truth:** all v1 scope, architecture, and build order live in [`QUESTLINE_PROJECT.md`](./QUESTLINE_PROJECT.md). Always check that doc before starting a task.

## Stack

- React Native + Expo (managed workflow, SDK 54)
- TypeScript (strict, `noUncheckedIndexedAccess`)
- Expo Router (file-based, typed routes)
- NativeWind v4 (Tailwind for RN)
- Supabase (Auth + Postgres) with RLS on every table
- Jest (jest-expo preset) for the XP engine
- ESLint + Prettier

AI, audio, animations, and monetization land in later phases per the spec.

## Supabase setup (Phase 1.2)

The migration ([`supabase/migrations/20260430000000_initial_schema.sql`](./supabase/migrations/20260430000000_initial_schema.sql)) is committed; the project itself is created manually:

1. Create a free-tier project at [supabase.com/dashboard](https://supabase.com/dashboard).
2. Copy `.env.example` to `.env.local` and paste the project's URL and anon key (Project Settings → API).
3. Apply the migration. Either:
   - **CLI (preferred):** `npx supabase link --project-ref <ref> && npx supabase db push`
   - **Manual:** open Supabase Studio → SQL Editor → paste the contents of the migration file → run.
4. Generate types: `npx supabase gen types typescript --linked > lib/types/database.ts`

After step 4, `lib/supabase.ts` queries are fully typed.

## Quickstart

```bash
npm install
npx expo start --web   # primary dev target on Windows
```

Other targets:

```bash
npx expo start --android   # requires Android Studio + emulator
npx expo start --ios       # requires macOS
```

## Scripts

- `npm run typecheck` — `tsc --noEmit`
- `npm run lint` — `expo lint` (Expo's ESLint flat config + Prettier)
- `npm run format` / `npm run format:check` — Prettier
- `npm test` / `npm run test:watch` — Jest (jest-expo preset)

## Project structure

```
app/
  _layout.tsx              # root Stack with AuthProvider + protected-route gate
  index.tsx                # session-aware entry redirect
  (auth)/                  # login, signup
  (onboarding)/            # cinematic, character-creation
  (main)/
    quest-board/           # index (list), new (create), [id] (detail)
    character-sheet.tsx
    settings.tsx
lib/
  engine/
    xp.ts                  # pure-TS XP engine: levels, tiers, modifiers
    xp.test.ts             # Jest tests — must stay green
  auth.tsx                 # AuthProvider + useAuth + useProtectedRoute
  quests.ts                # quest data layer (list, create, complete, abandon)
  supabase.ts              # Supabase client (platform-aware secure storage)
  types/
    database.ts            # regenerated by `supabase gen types typescript`
    models.ts              # hand-typed row models until gen types runs
supabase/
  config.toml              # Supabase CLI config
  migrations/              # SQL migrations (apply via `supabase db push`)
```
